# midnightloft：初遇与共同生活原型

这是一个 Godot 4 的极简 2D 群像叙事原型，开始界面提供“从 Week 1 周一开始”和“选择日期”两个入口；后者可重置状态并直接进入第一周任一天，周五预设为周四协商后的回响、周六预设为记得舞者忌口并参加饭局。连续流程从周一早晨生活例会开始，按周一至周日推进；例会生成一项周日之前完成的公共卫生待办，周一晚上喝茶并约定周六饭局，周二至周五体验聊天、工作和听歌等日常。周三听舞者聊排练时，她会提到自己不喜欢花生；周四晚大厨与舞者会因客厅排练空间发生分歧，玩家可支持一方或协商，周五出现对应回响，周六饭桌与周日例会也会根据两人关系呈现不同互动。周六活动开始前，舞者会分享准备社区舞蹈活动的顾虑，玩家的回应会在第二周周四得到回响；周六饭桌可以选一道菜递给她，若记住忌口会得到惊喜回应，误选花生汤也不会降低关系，并会在周日再次得到回响。周日由关系最高的室友先来对话，开场会根据关系值呈现熟络、自然或谨慎的语气；之后可生成本周日志并开启第二周。第二周周一根据上周打扫结果分支；周二由当前关系最高的室友带来后续短事件，周二选择会成为记忆标签，并在周三由同一位室友回应。若第一周选择在周六露台开启哲学家的 AI 伦理故事章，周日可继续谈他的经历，第二周周三则要决定如何回复合作方的上线提议。第二周周三之后进入周日合住复盘；若开启舞者支线，会先体验周四回响。游戏已有四位室友各自独立的关系值（0–100），选择会改变关系并影响后续对话；第一周还会记录大厨与舞者这一组相处值，并在周末日志中展示。周六活动可在平面图上点击三个房间中的两处安排，改变心情、关系、空间和睦值与外向值。厨房活动包含三次节奏操作；客厅活动可选择热闹、柔和或共同轮流选歌。生活日志记录选择、关系变化和待办结果。第一周周二加入工作选择与独立工作待办，工作声望会影响第二周周日是否出现可选的离开 Loft 结局。

完整的游戏构想、机制草案和当前进度见 [GAME_DESIGN.md](GAME_DESIGN.md)。Codex 后续协作约定见 [AGENTS.md](AGENTS.md)。

## 运行

1. 安装并打开 Godot 4。
2. 在项目管理器选择“导入”，选中本文件夹里的 `project.godot`。
3. 打开项目后按 F6/F5（或右上角运行按钮）。开始界面只有“开始 Week 1 · 周一”一个入口，之后按周一至周日推进；周日查看本周日志后可以开启下一周，或回到开始界面重新体验。

目前厨房、客厅、露台、家具和人物都由简单图形绘制，没有外部美术资源。回到开始界面会重新开始 Week 1。
